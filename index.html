Relato preliminar

Você perdeu o boletim de ocorrência

Aconteceu um assassinato no dia 15 de janeiro de 2018, em Montes Claros. Esses três dados — o que houve, quando e onde — é tudo de que você se lembra. O boletim em si, com a descrição da cena e o nome das testemunhas, sumiu.

O que sobrou foi o acesso ao banco de dados da polícia: endereços, carteiras de motorista, depoimentos, catracas de academia, registros de eventos da cidade. Quem estava lá, quem viu, quem mentiu, quem pagou — está tudo ali dentro, espalhado por oito tabelas.

Cabe a você juntar as peças. Escrevendo consultas SQL.

Este caso é inédito: foi criado especialmente para esta turma. Os nomes, as ruas e os culpados são diferentes dos de qualquer versão publicada na internet. Procurar a resposta no Google não vai funcionar — só investigar funciona.

Como as tabelas se ligam

Os caminhos entre uma tabela e outra

Nenhuma pista mora inteira em uma tabela só. Estas são as pontes que você vai usar o tempo todo:

JOIN cnh ON cnh.id = pessoa.id_cnh a aparência e o carro de uma pessoa
JOIN entrevista ON entrevista.id_pessoa = pessoa.id o que a pessoa depôs
JOIN academia_membro ON academia_membro.id_pessoa = pessoa.id a matrícula dela na academia
JOIN academia_checkin ON academia_checkin.id_membro = academia_membro.id os treinos daquela matrícula
JOIN checkin_evento ON checkin_evento.id_pessoa = pessoa.id os eventos que ela frequentou
JOIN renda ON renda.cpf = pessoa.cpf quanto ela ganha — repare: por CPF

Repare que o nome da tabela aparece inteiro dos dois lados do =. É mais longo de escrever, mas você lê a condição e entende na hora o que está sendo ligado a quê — sem precisar voltar lá em cima para lembrar o que era c ou p.

Perícia técnica

Detalhes que derrubam quem não presta atenção

  • Datas são do tipo DATE. Escreva entre aspas, no formato 'AAAA-MM-DD' — o dia do crime é '2018-01-15'. Como é data de verdade, você tem YEAR(), MONTH(), DAYNAME(), DATEDIFF() e DATE_FORMAT() à disposição.
  • Horários são do tipo TIME, no formato 'HH:MM:SS'. Para calcular quanto durou um treino, use TIMEDIFF(hora_saida, hora_entrada).
  • altura está em centímetros. 1,70 m é 170.
  • cpf é texto, não número — porque CPF não é quantidade, é identificação. Se fosse número, um CPF começando com zero perderia o zero. Mesma coisa com placa_veiculo, guardada sem hífen (HTZ4297). Guarde cru, formate só na hora de exibir.
  • pessoa.id_cnh pode ser nulo — nem todo mundo dirige. E o teste é IS NULL, nunca = NULL.
  • Acentos não travam a busca. O banco usa grafia correta (Januária), mas a comparação ignora acento: WHERE cidade = 'Januaria' encontra do mesmo jeito.

Aviso

A maioria dos filtros parciais devolve várias pessoas — isso é de propósito. Só combinando todas as pistas de um depoimento você chega a um único nome. Se a sua consulta retornou 14 suspeitas, faltou uma condição. Consulta que roda não é o mesmo que consulta certa.

Sua missão

Descubra quem matou

E, quando achar, desconfie: será que essa pessoa agiu sozinha?

Comece pelo boletim de ocorrência.

SELECT *
FROM boletim_ocorrencia
WHERE data = '2018-01-15'
  AND tipo = 'assassinato'
  AND cidade = 'Montes Claros';

A descrição desse boletim aponta para as testemunhas. O depoimento das testemunhas aponta para o assassino. E o depoimento do assassino aponta para alguém que você ainda não imagina.

Cada pista que você encontrar é a pergunta da próxima consulta. Anote tudo em consultas.sql — inclusive as tentativas que deram errado. Elas mostram o seu raciocínio e valem tanto quanto as que acertaram.

Consulta rápida

O que cada comando faz

Clique em qualquer item para ver um exemplo pronto e copiar. Todos os exemplos rodam neste banco — mas nenhum deles resolve o caso. São só demonstrações de uso, para você adaptar às suas próprias perguntas.

Escolher e filtrar

SELECT escolhe quais colunas aparecem

Use * para trazer todas as colunas, ou liste os nomes separados por vírgula para trazer só o que interessa.

SELECT nome, endereco_rua, endereco_numero
FROM pessoa
LIMIT 10;
DISTINCT lista os valores sem repetir

Ótimo para descobrir quais valores existem numa coluna.

SELECT DISTINCT cidade
FROM boletim_ocorrencia
ORDER BY cidade;
WHERE filtra quais linhas entram no resultado

Texto e datas vão entre aspas simples. Números, não.

SELECT nome, endereco_rua, endereco_numero
FROM pessoa
WHERE endereco_rua = 'Avenida do Cerrado';
AND / OR combina várias condições

AND exige que todas sejam verdadeiras. OR aceita qualquer uma.

SELECT data, tipo, cidade
FROM boletim_ocorrencia
WHERE tipo = 'furto'
  AND cidade = 'Januária';

SELECT id, cor_cabelo, idade
FROM cnh
WHERE cor_cabelo = 'loiro'
   OR cor_cabelo = 'grisalho';
<> e NOT o contrário da condição

<> quer dizer "diferente de". Também existem >, <, >= e <= para números e datas.

SELECT data, tipo, cidade
FROM boletim_ocorrencia
WHERE cidade <> 'Montes Claros'
LIMIT 10;
BETWEEN uma faixa de valores, incluindo as pontas

Funciona com números e com datas.

SELECT id, idade, altura
FROM cnh
WHERE altura BETWEEN 180 AND 190;

SELECT data, tipo, cidade
FROM boletim_ocorrencia
WHERE data BETWEEN '2017-03-01' AND '2017-03-31';
IN vale qualquer valor de uma lista

Evita escrever vários OR seguidos.

SELECT data, tipo, cidade
FROM boletim_ocorrencia
WHERE cidade IN ('Pirapora', 'Salinas', 'Bocaiúva');
LIKE procura um pedaço de texto

% vale por qualquer quantidade de caracteres (inclusive nenhum). _ vale por exatamente um.

-- começa com
SELECT nome FROM pessoa WHERE nome LIKE 'Carlos%';

-- termina com
SELECT nome FROM pessoa WHERE nome LIKE '%Silva';

-- contém, em qualquer posição
SELECT nome FROM pessoa WHERE nome LIKE '%Souza%';

-- o _ marca uma posição exata
SELECT placa_veiculo FROM cnh WHERE placa_veiculo LIKE 'A_C%';
IS NULL encontra campos vazios

Vazio não é zero nem texto em branco. E atenção: = NULL nunca funciona — sempre devolve nada. O certo é IS NULL ou IS NOT NULL.

SELECT nome, id_cnh
FROM pessoa
WHERE id_cnh IS NULL
LIMIT 10;

Ordenar, limitar e renomear

ORDER BY ordena o resultado

ASC é do menor para o maior (padrão) e DESC é do maior para o menor.

SELECT nome, endereco_rua, endereco_numero
FROM pessoa
WHERE endereco_rua = 'Rua do Pequi'
ORDER BY endereco_numero DESC;
LIMIT corta a quantidade de linhas

Combinado com ORDER BY, serve para pegar "o maior", "o mais novo", "os cinco primeiros".

SELECT id, idade
FROM cnh
ORDER BY idade DESC
LIMIT 5;
AS dá um nome melhor à coluna do resultado

Só muda o cabeçalho que aparece na tela — não altera o banco.

SELECT nome            AS morador,
       endereco_rua    AS rua,
       endereco_numero AS numero
FROM pessoa
LIMIT 10;

Contar e resumir

COUNT conta quantas linhas

COUNT(*) conta todas as linhas. COUNT(coluna) ignora as que estão vazias.

SELECT COUNT(*) AS total_de_pessoas
FROM pessoa;

SELECT COUNT(*) AS ocorrencias_em_2017
FROM boletim_ocorrencia
WHERE YEAR(data) = 2017;
SUM soma os valores de uma coluna

Só faz sentido em coluna numérica.

SELECT SUM(renda_anual) AS soma_das_rendas
FROM renda;
AVG calcula a média

Costuma vir acompanhado de ROUND, senão saem muitas casas decimais.

SELECT AVG(idade) AS idade_media
FROM cnh;
MIN e MAX o menor e o maior valor

Funcionam com números, datas e até texto (aí é ordem alfabética).

SELECT MIN(altura) AS mais_baixo,
       MAX(altura) AS mais_alto
FROM cnh;

SELECT MIN(data) AS primeiro_registro,
       MAX(data) AS ultimo_registro
FROM boletim_ocorrencia;
ROUND arredonda o número

O segundo argumento é quantas casas decimais manter.

SELECT ROUND(AVG(idade), 1) AS idade_media,
       ROUND(AVG(altura))    AS altura_media
FROM cnh;

Agrupar

GROUP BY resume os dados por categoria

Transforma "quantas linhas existem" em "quantas linhas existem de cada tipo". Toda coluna do SELECT ou está no GROUP BY, ou está dentro de COUNT, SUM, AVG…

SELECT cidade, COUNT(*) AS ocorrencias
FROM boletim_ocorrencia
GROUP BY cidade
ORDER BY ocorrencias DESC;
HAVING filtra DEPOIS de agrupar

Esta é a confusão mais comum: WHERE filtra as linhas antes de agrupar; HAVING filtra o resultado do agrupamento. Se a condição usa COUNT, SUM ou AVG, ela tem que estar no HAVING.

SELECT tipo, COUNT(*) AS quantidade
FROM boletim_ocorrencia
GROUP BY tipo
HAVING COUNT(*) > 100
ORDER BY quantidade DESC;

Juntar tabelas

JOIN junta duas tabelas pela coluna que as liga

Traz só as linhas que têm par nas duas tabelas.

SELECT pessoa.nome, cnh.marca_veiculo, cnh.modelo_veiculo
FROM pessoa
JOIN cnh ON cnh.id = pessoa.id_cnh
WHERE cnh.marca_veiculo = 'Fiat'
LIMIT 10;
LEFT JOIN mantém todas as linhas da primeira tabela

Quem não tem par na segunda tabela aparece assim mesmo, com as colunas dela vazias. Use quando quiser ver justamente quem não tem correspondência.

SELECT pessoa.nome, cnh.marca_veiculo
FROM pessoa
LEFT JOIN cnh ON cnh.id = pessoa.id_cnh
LIMIT 15;
Subconsulta uma consulta dentro da outra

O banco resolve primeiro a de dentro (entre parênteses) e usa o resultado dela na de fora.

SELECT nome, endereco_rua
FROM pessoa
WHERE cpf IN (SELECT cpf
              FROM renda
              WHERE renda_anual > 1000000);

Trabalhar com texto

CONCAT junta pedaços de texto num só 
SELECT CONCAT(nome, ' — ', endereco_rua, ', ', endereco_numero) AS ficha
FROM pessoa
LIMIT 10;
UPPER e LOWER tudo em maiúscula ou minúscula 
SELECT nome,
       UPPER(nome) AS em_maiuscula,
       LOWER(nome) AS em_minuscula
FROM pessoa
LIMIT 5;
LEFT, RIGHT e MID recorta pedaços de um texto

LEFT pega do começo, RIGHT do fim, e MID pega a partir de uma posição.

SELECT placa_veiculo,
       LEFT(placa_veiculo, 3)  AS letras,
       RIGHT(placa_veiculo, 4) AS numeros,
       CONCAT(LEFT(placa_veiculo, 3), '-', RIGHT(placa_veiculo, 4)) AS formatada
FROM cnh
LIMIT 10;
LENGTH quantos caracteres tem o texto 
SELECT nome, LENGTH(nome) AS tamanho
FROM pessoa
ORDER BY tamanho DESC
LIMIT 5;

Trabalhar com data e hora

YEAR, MONTH e DAY separa as partes de uma data

Só funcionam porque a coluna é do tipo DATE.

SELECT data,
       YEAR(data)  AS ano,
       MONTH(data) AS mes,
       DAY(data)   AS dia
FROM boletim_ocorrencia
LIMIT 10;
DAYNAME diz o dia da semana de uma data

Responde em inglês: Monday, Tuesday…

SELECT data, DAYNAME(data) AS dia_da_semana
FROM academia_checkin
LIMIT 10;
DATE_FORMAT exibe a data do jeito que você quiser

%d dia, %m mês, %Y ano com 4 dígitos.

SELECT data,
       DATE_FORMAT(data, '%d/%m/%Y') AS data_brasileira
FROM boletim_ocorrencia
LIMIT 10;
DATEDIFF quantos dias entre duas datas

A ordem importa: primeira menos a segunda.

SELECT nome, data_inicio,
       DATEDIFF('2018-01-31', data_inicio) AS dias_de_matricula
FROM academia_membro
LIMIT 10;
HOUR e MINUTE separa as partes de um horário

Servem para agrupar por faixa de horário.

SELECT hora_entrada,
       HOUR(hora_entrada)   AS hora,
       MINUTE(hora_entrada) AS minuto
FROM academia_checkin
LIMIT 10;
TIMEDIFF quanto tempo passou entre dois horários 
SELECT hora_entrada, hora_saida,
       TIMEDIFF(hora_saida, hora_entrada) AS duracao
FROM academia_checkin
LIMIT 10;
